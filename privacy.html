Об этой политике

Как U-Write и этот сайт работают с данными. Политика включает синхронизацию Google Диска, подготовленную для версии 0.6.2. Контакт: uwrite.app@gmail.com.

Данные на компьютере

Рукопись, материалы проекта, настройки и список недавних книг хранятся локально. Проверка орфографии и пунктуации выполняется на компьютере. В текущей сборке нет аналитики использования и автоматической отправки рукописей или отчётов о сбоях разработчику.

Google Диск

Синхронизация необязательна и включается отдельно для каждой книги. Приложение напрямую передаёт Google снимки выбранного проекта: главы, заметки, персонажей, материалы мира, комментарии, вложения и включённую в пакет историю. Сервер разработчика в обмене не участвует. Адрес почты и идентификатор Google-аккаунта используются для отображения аккаунта и связи с его облачными книгами.

Доступ и защита

Разрешение drive.file даёт доступ к файлам, созданным приложением или предоставленным ему пользователем, а не ко всему Диску. Вход проходит в браузере на странице Google; приложение не получает пароль. Токены доступа и его обновления сохраняются локально с защитой Windows DPAPI, связи книг — в локальных служебных файлах. Передача идёт по HTTPS. Облачные пакеты не шифруются отдельным паролем пользователя.

Отключение и удаление

Переключатель книги останавливает синхронизацию. Отключение аккаунта удаляет сохранённые токены. Оба действия сохраняют существующие книги на Диске. Отозвать разрешение можно в подключениях Google-аккаунта, удалить облачные файлы — на Диске, с учётом его корзины и правил хранения. Локальные книги, резервные копии и .uwb удаляются отдельно. Старые облачные снимки и защитные локальные копии не очищаются автоматически. Разработчик не может удалить их удалённо.

Использование данных Google

Данные используются только для синхронизации и работы с подключённым аккаунтом — без рекламы, продажи данных и обучения ИИ. U-Write соблюдает Google API Services User Data Policy и Google Workspace API User Data and Developer Policy, включая требования Limited Use.

Обновления и сайт

Обновления загружаются с GitHub без передачи содержимого книг; автоматические обновления можно отключить. На сайте нет форм, аналитики, рекламных скриптов или собственных cookies. GitHub Pages получает технические данные запросов и хранит IP-адреса для безопасности. Правила сервисов: GitHub, Google.

Поддержка и обращения о данных

Если вы пишете на uwrite.app@gmail.com, автор получает адрес и имя отправителя, текст и вложения. Они используются для ответа; Gmail обрабатывает переписку по правилам Google. Материалы хранятся, пока нужны для обращения или исполнения требований закона. По этой же почте можно запросить сведения, исправление или удаление данных, присланных вами в поддержку. Это не затрагивает ваши локальные и облачные файлы. При изменении обработки политика обновляется; новое согласие запрашивается, когда оно требуется.
